Multi-Entity Tax Advisor Handoff: Ownership, Returns and Responsibilities

Give the incoming advisor one coherent map of the businesses. An organized handoff reduces repeated requests and makes gaps in responsibility visible before a filing or transaction deadline.

Build the entity inventory

Record legal name, tax identification number, state, tax classification, owners and ownership percentages for each entity. Keep sensitive identifiers in a secure intake system. This public checklist is a guide to the fields you need, not a place to submit them.

Match returns to records

Identify the latest filed return and any extensions, amendments, notices or unresolved questions. Pair each entity with its general ledger, balance sheet, payroll and ownership records. Mark the status of the current year instead of assuming the prior preparer completed every step.

Trace transactions between entities

List rent, management fees, loans, reimbursements and distributions that cross entity boundaries. Identify the counterparties, written agreements and ledger accounts. Ask the advisor which balances need reconciliation before planning or filing.

Agree the work split

Document who prepares each return, manages notices, processes payroll and implements any recommended change. Request a written engagement scope and a secure transfer method. Keep a record of access granted and remove obsolete access when the transition is complete.

Printable preparation worksheet

Use a private working copy to record the document location, outstanding question and person responsible for completing each item. These blank fields do not submit or store information online. Keep sensitive data in your secure records.

Before you request advice

Mark unresolved items clearly and explain any deadline that may affect the review. Ask for an individualized conclusion and a written work scope before relying on a recommendation. A completed preparation worksheet is evidence organization, not approval of a tax position.
